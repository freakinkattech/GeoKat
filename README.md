## 2. GeoKat Simulator & Game Features

### First-Person Player POV (Arena Locomotion)
- **Physics Locomotion:** Smooth acceleration and momentum inertia using <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>.
- **Sprint & Stealth:** Hold <kbd>Shift</kbd> for tactical sprinting ($1.6\times$ velocity) or press <kbd>C</kbd> for stealth crouching ($0.95\text{m}$ eye level).
- **Vertical Leaps & Gravity:** Realistic jumping (<kbd>Spacebar</kbd>) with downward gravitational acceleration and physical landing impacts.
- **Tactical Headlamp (<kbd>F</kbd>):** Toggle a real-time directional spotlight attached to your camera for exploring dark arena sectors.
- **Omnidirectional Sonar Ping (<kbd>Q</kbd>):** Sweep the arena to ping all 360° node signatures, pulsing the holographic reticle.
- **Rotating Tactical Mini-Map:** Real-time HUD radar tracking player heading relative to honest nodes (cyan/green), regional hubs (amber), astroturf bots (rose), and the central boss (purple).

### Transcendence Orbit ("Scope Out")
With one click, exit your ground avatar's body and fly into orbit around the **Macro 3D Geodesic Sphere overhead**. Observe the entire Global Professional Gaming Alliance network, watch real-time telemetry packets pulse across vertices, and witness how local ground actions alter global tournament accuracy.

### Procedural Web Audio Soundscape
Built natively with the Web Audio API (zero external sound files):
- Rhythmically synchronized footstep audio matching walk and sprint cadences.
- Locomotion whooshes, jumping liftoffs, and landing impacts.
- Radar sonar pulses, flashlight clicks, and node proximity hums.
- Dialogue typing blips, quest completion fanfares, and Byzantine Sybil alarm buzzers.
- Master audio mute toggle.

### Progressive 4-Act Campaign Storyline
1. **Act 1: The Monolith's Shadow:** Wake up under the monopoly of the Legacy Gatekeeper Hub. Connect with Algorithmic Scout #14 to transmit your first unedited telemetry signal.
2. **Act 2: Weaving the Alliance Lattice:** Collaborate with EuroTactics Pod #09 to unlock your first automated counter-playbook, establishing a reciprocal surplus ($R_f = 1.65\times$).
3. **Act 3: Astroturf Infiltration:** Locate, scan, and audit 3 coordinated Byzantine Sybil bots. Watch quadratic damping decay their influence to zero.
4. **Act 4: Decoupling & Alliance Sovereignty:** Confront the Gatekeeper Hub with the unified power of the peer network. Cross the critical phase threshold ($\Psi_{\text{decouple}} > 1.0$), liberate the league, and unlock the full Geodesic Orbit.

### Memory Save State Engine (JSON Export & Import)
- **Persistent Local Storage:** Automatically preserves chapter progression, player coordinates, FRS score, $R_f$ ratio, and inventory across browser sessions.
- **Export Save State (.JSON):** Download a standalone `.json` save file (e.g., `geokat_save_act2_frs89.json`) to back up your campaign or share your exact world state with friends.
- **Import Save State (.JSON):** Load any `.json` save file to immediately resume that exact storyline act, inventory, and arena position.

### Decentralized Peer-to-Peer Network Fabric
Powered by browser-native `BroadcastChannel` APIs. When two or more tabs or browser windows are opened, the instances automatically discover each other, link into an ad-hoc gossip mesh, synchronize peer counts, and broadcast live P2P signals directly across tabs with zero server infrastructure.
